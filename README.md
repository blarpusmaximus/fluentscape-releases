# Fluentscape for Android

Download builds of the [Fluentscape](https://fluentscape.com) Android app. Learn a language through an Old School RuneScape-style skilling game.

**[Download the latest Fluentscape.apk](https://github.com/blarpusmaximus/fluentscape-releases/releases/latest/download/Fluentscape.apk)**

Open the downloaded file on your phone. If Android asks, allow your browser to install apps.

This is an early preview: only Sentence questions so far, and progress stays on the phone.
